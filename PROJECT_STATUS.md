# GUS Research Lab - Project Status & Phase Breakdown

## 🚀 Project Overview
A professional, NASA/OpenAI/DeepMind-inspired research lab website built with **React 18 / Vite / Tailwind CSS** (Frontend) and **Spring Boot 3.2 / JPA / PostgreSQL & H2 / JWT** (Backend). The platform showcases advanced research in Artificial Intelligence, Machine Learning, Physics, Quantum Computing, UAP Research, and Space Science.
